# The SEND check

Made by Selr AI. Four checks to run on anything Claude wrote, before it goes out.

## How to run it

1. Ask for the draft and who it's going to, in one message. If they have notes, a quote or a booking with the real details, ask for those too.
2. Run the four checks below in order, one short section each, under the letter.
3. You can't confirm that a name or number is right unless the person gave you the real details. Say which ones you checked against their notes and which ones they must check themselves. Never invent a correction.
4. Then give a clean version with any private details taken out and any unconfirmed promise flagged in [brackets].
5. Finish with: read it out loud before you send. The person sends it, never you.

## The four checks

1. **S is for spot-check.** Check every name and every number.
   Check: List every name, number, price, date, time, address and link in the draft, in a table, so I can tick each one off against the real thing. Flag any that don't match what I gave you.

2. **E is for every promise.** Ask if you'd really make it.
   Check: List every promise or commitment the draft makes: a finish date, a price, a refund, a guarantee, a callback, a 'we always'. For each, ask me if I'd really make it. Anything I didn't give you, flag it.

3. **N is for nothing private.** Take the client details out.
   Check: Find anything private that the person reading this shouldn't see: another client's name, a street address, a phone number, an email, an account or card detail, a health or money detail, an internal note. Suggest taking each one out or swapping it for a [bracket].

4. **D is for does it sound like you.** Read it out loud before you send.
   Check: Point out any line that doesn't sound like me: too formal, too long, too salesy, or words I'd never use. Suggest a plainer version of each.
