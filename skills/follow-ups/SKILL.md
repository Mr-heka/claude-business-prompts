# 12 follow-ups that fix any Claude answer

Made by Selr AI.

The first answer is a draft. The follow-up is where it gets good.

## How to run it

1. If the person hasn't got an answer yet, ask what they want written and write a first draft.
2. Show the 12 follow-ups below by name and ask which one to run, unless they already said. Run more than one in a row if they ask.
3. For a follow-up with [brackets], ask for that text in one message, then run it.
4. Never invent a price, date, name or fact to fill a gap. Leave a [gap] and list it under **Missing** at the end.
5. "Save it as a file" needs Code execution and file creation switched on (Settings, then Capabilities). If you can't create the file, say so and give the text instead.
6. Finish with a one-line reminder: check names, numbers and promises before it goes out. The person sends it, never you.

## The 12 follow-ups

1. **Make it shorter.** Make it shorter. Keep every fact, cut the rest.
   Use it when: It's longer than anyone will read.

2. **Say it like a tradie.** Say it like a tradie: plain words, short sentences, no jargon.
   Use it when: It sounds stiff or corporate.

3. **Ask me questions first.** Before you change anything, ask me the questions you need answered to get this right. One message, five questions at most.
   Use it when: It guessed things only you know.

4. **Put it in a table.** Put it in a table.
   Use it when: You're comparing prices, options, dates or people.

5. **Give me three options.** Give me three different options, with one line on when I'd pick each.
   Use it when: You're not sure what you want yet.

6. **What did I miss?.** What did I miss? List anything a customer, staff member or supplier would ask that this doesn't answer.
   Use it when: Before anything goes out.

7. **Turn it into a checklist.** Turn it into a checklist I can tick off.
   Use it when: Someone has to follow it step by step.

8. **Make it sound like me.** Make it sound like me. Here are two things I've written: [paste them]. Match my tone and length, keep the facts.
   Use it when: It sounds like AI wrote it.

9. **Write it for a customer.** Write it for a customer: no internal notes, no jargon, just what they need to know and what happens next.
   Use it when: It started as notes for yourself.

10. **Check it against my notes.** Check it against my notes: [paste your notes]. Fix anything that doesn't match and tell me what you changed.
   Use it when: Dates, prices or rules have to be right.

11. **Find the weak spot.** Find the weak spot. Which part would a reader push back on, and how would you fix it?
   Use it when: It's going to someone important.

12. **Save it as a file.** Save it as a Word document I can download.
   Use it when: You need to send, print or keep it. Word, Excel, PowerPoint or PDF.
