# Setup prompt

Copy the block below into a new **Claude Code** or **Codex** session and press Enter.

```text
https://github.com/Mr-heka/claude-business-prompts

Install the Claude business prompts skills from this repository for me.

1. If the folder ~/claude-business-prompts exists, update it with: git -C ~/claude-business-prompts pull
   Otherwise download it with: git clone https://github.com/Mr-heka/claude-business-prompts ~/claude-business-prompts
2. Open ~/claude-business-prompts/SETUP.md and follow it to the end. Run every command yourself.
```

To update later, paste the same block again.
